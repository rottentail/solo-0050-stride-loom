# 折步台

在浏览器中编排角色动作图、观察输入缓冲与转场，并交接可独立复演的动作资产。

## 启动

需要 macOS 或 Linux 上的 Python 3.11 或更新版本，不需要安装依赖。在项目根目录运行 `python3 -m stride serve`，访问 `http://127.0.0.1:8675`。用 `--data` 或 `STRIDE_LOOM_DATA` 指定修订目录，默认写入项目目录下的 `.stride-data`。用 `--port` 指定监听端口。

打开「潮灯搬运体」，选一段预演，点击「运行预演」。拖动时间轴查看穿越源帧、事件、候选边与世界位移。左侧可比较原速和镜像快进。可编辑场景的命令序列、根轨、事件和转场，也可在「源资料」中调整完整动作图。保存使用载入时的修订作为并发基准。历史修订可以读回，随后仍以浏览器获知的最新工作头作为下一次保存的基准。

从已保存的修订下载指定场景的交接包。另一个实例也可以校验和复播该文件。包封装图、场景和确定性轨迹，核对来自内容的一致性。工作台预期运行在用户本机或受信开发环境。

## 验证

`python3 -m compileall -q stride` 检查 Python 模块。`python3 -m stride walkthrough all` 在临时目录和临时端口通过实际 HTTP 接口检查十条流程。任一检查失败则进程返回非零。输入、结果和退出状态都会显示在输出中。自动化测试留待后续，生产入口自检不会读取或更改默认工作目录。
